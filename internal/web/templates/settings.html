Источники CDN

Официальные списки диапазонов CDN. service — имя сервиса, которое классификатор сопоставляет источнику (cloudflare/aws/google/fastly); по нему сервис без доменов получает ASN. asn — ключ каталога, который выбирает список официальных диапазонов. parser — формат ответа: text (по строке CIDR), google (gstatic JSON), aws (ip-ranges JSON, только CloudFront), fastly (public-ip-list JSON).
